Learning Outcomes

Students are able to:

  • process and analyse vector and raster geospatial data in a script-based workflow
  • combine script-based geospatial workflows with GIS desktop software (QGIS)
  • independently carry out spatial analyses and transformations of geospatial datasets
  • develop automated and reproducible geospatial workflows
  • visualise and communicate spatial information in a task-appropriate manner
  • use AI-assisted tools to support coding and geospatial analysis tasks
  • apply learned methods to practical problems in environmental and spatial analysis

Course Structure

The course runs over 14 weeks and is organised around three thematic blocks, each pairing a method focus with an application domain. Each block has a main two-week session and one advanced follow-up session in weeks 9–11. The second half closes with a semester project phase.

Semester Project

Students carry out a semester-long project in which they apply the methods from all three blocks to a dataset of their choice. The project runs in parallel with the teaching blocks and culminates in a written report.

The oral exam tests understanding of the methods and results — not the project output itself. This guards against unreflective use of AI tools.
