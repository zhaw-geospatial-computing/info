Capacity Constraints

The 14-week semester is not fully available for teaching:

  • ~1 week: project proposal presentations
  • ~1 week: coaching sessions (mandatory attendance)

This leaves roughly 12–13 weeks for teaching inputs, shared between three lecturers — approximately 3–4 weeks per person.

Assessment Structure (confirmed)

Students complete three pass/fail predicates and one graded exam:

Component Type Description
Project proposal Predicate pass/fail
Written project report Predicate pass/fail
Coaching session attendance Predicate pass/fail
Oral end-of-module exam (~20 min) Grade 100% weight

The oral exam tests understanding of methods and results, not the project output itself. This is a deliberate design choice to guard against unreflective AI use. All predicates must be passed to sit the exam.

Proposed Course Framework

The course is organised along two axes: methods and domains.

Methods Axis

Each lecturer teaches one or more method blocks. Each block is anchored to a specific application domain (see below), giving students a concrete dataset and problem to work with. The following methods are currently on the list — part of the meeting agenda is to reduce / enhance and confirm this list:

  1. Spatial pattern analysis — autocorrelation, hotspot analysis, interpolation
  2. Uncertainty quantification — Monte Carlo simulation, error propagation, sensitivity analysis
  3. Image processing — automated detection from camera trap imagery (e.g. MegaDetector)
  4. Multi-Criteria Analysis (MCA) — spatial suitability modelling, decision support
  5. Network Analysis — routing, connectivity, accessibility

We likely have capacity for 3–4 of these, not all five. Selection is a key agenda item.

Domains Axis

Each method block is taught in the context of one application domain. Students then choose a domain for their own semester project and apply the methods they have learned. Current candidate domains:

  1. Wildlife Monitoring — camera trap data, opportunistic species observations
  2. Vegetation Ecology — spatial and temporal vegetation surveys
  3. Hydrology — vectorised river networks (no remote sensing or drone data)
  4. Environmental Planning — visitor management, quiet area mapping

Toolsets

The following tools are introduced where relevant, rather than as standalone blocks:

  • R / RStudio
  • QGIS
  • QGIS Model designer
  • Building a QGIS Plugin — Python-based extension
  • Databases (PostGIS / SQLite)
  • QField
  • Webmapping
